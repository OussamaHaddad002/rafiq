# Tarifs 2026 - Clinique Rafiq

Document fictif, créé pour une démonstration. La Clinique Rafiq n'existe pas.

Tarifs en dinars tunisiens (DT), toutes taxes comprises, valables à partir du 1er janvier 2026.

## Consultations

| Spécialité | Tarif |
|---|---|
| Médecine générale | 45 DT |
| Cardiologie | 80 DT |
| Médecine dentaire (dentiste) | 50 DT |
| Pédiatrie | 60 DT |
| Gynécologie | 70 DT |
| Dermatologie | 65 DT |
| Ophtalmologie | 55 DT |
| Téléconsultation (toutes spécialités) | 40 DT |

- Une consultation de contrôle avec le même médecin dans les 15 jours est facturée à moitié prix.
- Les tarifs des consultations ne comprennent pas les examens complémentaires (voir page 2).
- Le paiement se fait à l'accueil, avant la consultation.
